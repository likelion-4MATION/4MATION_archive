자유 서술이 아니라 항목별로 입력합니다. 잘못 쓰면 AI가 엉뚱하게 동작할 수 있어 형식을 고정했습니다.

첨부문서 관리

—
원본 crawler/data/doc_attachments.json 과 crawler/data/files/ 는 건드리지 않습니다. 고친 표시명과 교체본은 별도 파일에 쌓이므로 재크롤링을 해도 유지됩니다.
내려받기는 크롤러가 이미 받아 둔 원본 파일을 그대로 내려줍니다. 교체는 새 파일을 올려 그 자리를 대신하게 하고, 원본은 지우지 않아 언제든 되돌릴 수 있습니다.

첨부 직접 추가

크롤링으로 못 가져온 서식이나 외부 자료를 관리자가 직접 올립니다.

이전 타기관 안내 사전 (사용 중지)

소관이 아닌 질문에 안내할 기관·연락처입니다. 여기에 없는 주제는 자동으로 일반 거절 문구로 내려갑니다.
주소·전화번호는 크롤링 원문에 실재하는 값만 넣으세요. 답변에 그대로 나갑니다.

고급 설정 🔒 잠김

개발자 확인 후 잠금 해제. 값을 바꾸면 "검증된 프리셋 아님" 배지가 상시 표시됩니다.
이 5개 값(RRF_ALPHA·RRF_K·BF_BOOST·FACET_BOOST·BF_DOC_CAP)은 8,064개 조합을 전수 탐색해 고른 한 세트입니다. 하나만 바꾸면 검증되지 않은 조합이 됩니다. 또한 현재 코퍼스와 한 세트라 재빌드 후에는 재튜닝이 필요합니다.

문서 처리 (재빌드 필요) 🔒

이 탭의 값만 저장 즉시 반영되지 않습니다. 문서를 다시 잘라 전체를 재계산해야 합니다.
값을 바꾸면 세 가지가 함께 무효화됩니다 — ① 검색 프리셋 3종(개발자 재튜닝 필요) ② 검색 인덱스 전체 ③ 되묻기 조합 테이블의 근거 연결. 왼쪽 [한 번에 실행]을 쓰면 검증 → 빌드 → 재검증 순으로 처리하며, 1단계 검증이 현재보다 나쁘면 빌드 전에 멈추고 확인을 요청합니다.

파라미터

값을 움직이면 오른쪽에 예상 결과가 바로 나옵니다.

예상 결과 현재 설정

평가셋 TEST 430문항 · 지표 = 앵커 hit@5
검증·재빌드 버튼은 왼쪽 사이드 패널에 있습니다. 어느 탭에서 무엇을 바꾸든 거기서 한 번에 실행하고, 결과는 위 결과창에서 봅니다.

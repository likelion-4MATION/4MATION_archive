# 큐폼 시험 질의셋 — 데모 체크리스트

> **대상** `python -m uvicorn web.main:app --host 127.0.0.1 --port 8501`(현재 정식 웹 UI) · 작성 당시 `streamlit run chatbot/app.py`(현 레거시, 포트 8502) · **브랜치** `Qform_ver1` · **작성일** 2026-08-07
> **쓰는 법** 왼쪽 질의를 그대로 붙여넣고, **기대 동작** 칸과 다르면 그게 버그 리포트다.
> 슬롯은 답변 아래 "확정된 조건" 칩·캡션에, 첨부는 "관련 서식·첨부파일 (N건)" 영역에 표시된다.
> 기대 슬롯은 2026-10-12 코드로 다시 맞췄다 — ver4 M6-a부터 `party`(송금인·수취인)는 질의에 근거 어휘가 있을 때만 채운다.
> 질의·기대 동작은 두 UI 공통이다 — 화면 배치(토글·버튼 위치)만 각 UI를 따른다.

---

## A. 되묻기 없이 바로 답 — `sub_task` 7종 (각 1턴)

가장 먼저 볼 것. **되묻기가 뜨면 안 된다.**

| # | 질의 | 기대 슬롯 | 기대 첨부 |
|---|---|---|---|
| A1 | 착오송금 반환지원 제도가 뭔가요? | `제도안내` | **0건** (설명만) |
| A2 | 착오송금 반환 신청을 철회하고 싶어요 | `신청철회` | 1건 — 취소신청서양식 |
| A3 | 부당이득반환채권 매입계약을 해제하려면 어떻게 하나요? | `매입계약해제` | 1건 — 매입계약해제신청서양식 |
| A4 | 반환금 받을 계좌를 바꾸고 싶어요 | `수령계좌변경` | 1건 — 수령계좌변경신청서양식 |
| A5 | 위임한 대리인을 다른 사람으로 변경하려면? | `대리인변경` · 대리인 | 1건 — 위임해지통지서양식 |
| A6 | 착오송금 반환 요구에 이의제기하고 싶습니다 | **수취인** · `이의제기` | 1건 — 이의제기서양식 |
| A7 | 착오송금 반환하면서 낸 이체수수료 환급받을 수 있나요? | `이체수수료환급` | 1건 — 이체수수료환급신청서양식 |

> **A2~A5가 이번 스프린트의 핵심**이다. 기존 KDIC 챗봇(예솜24)에 없는 **숨은 분기** 4개다.

## B. 되묻기 1턴 — 본인 경로

| # | 질의 | 되묻기 | 답변 | 결과 |
|---|---|---|---|---|
| B1 | 착오송금 반환 신청 서류가 뭐예요? | **"반환신청은 누가 하시나요?"** (예: 본인, 대리인) | `본인이 직접 신청해요` | C02 · 첨부 3서식 |
| B2 | 〃 (같은 질의) | 〃 | **[잘 모르겠어요 — 이대로 답변받기] 버튼** | 7행 유지 · 첨부 5서식 |

**B2가 탈출구 확인**이다. 건너뛰어도 답이 나오고, 첨부가 **넓게** 나온다(좁히지 않고 안전 측). 이게 graceful degradation이다.

---

## C. 되묻기 2턴 — 대리인 경로 ★ 이번 데모의 하이라이트

| # | 질의 | 1턴 | 2턴 | 결과 |
|---|---|---|---|---|
| C1 | 착오송금 반환 신청하려는데 필요한 서류 알려주세요 | `대리인이 신청해요` | **"누구를 대리해서 신청하시나요?"** → `법인이요` | C04 · 법인 안내 |
| C2 | 착오송금 반환 신청 서류 알려주세요 | `제가 대신 접수해요` | → `미성년자 자녀 대신이에요` | C06 · **친권합의서 포함 4서식** |
| C3 | 착오송금 반환 신청 서류 알려주세요 | `대리인이요` | **[잘 모르겠어요 — 이대로 답변받기]** | 6행 유지 · 첨부 7서식 |

> **2번째 질문이 뜨는지**를 꼭 보시라. 08-07에 고친 버그가 이 지점이다. 이게 안 뜨면 법인 대리인이 **사업자등록증 안내를 못 받는다.**
>
> C2에서 `05_친권합의서양식`이 첨부에 뜨는지도 확인. 이게 조합 조인이 실제로 작동한다는 증거다.

## D. 슬롯 선반영 — 되묻기 없이 한 번에

사용자가 처음부터 정보를 다 말한 경우. **되묻기 0턴**이어야 한다.

| # | 질의 | 기대 |
|---|---|---|
| D1 | 법인이 잘못 송금했는데 반환 신청 서류가 뭔가요? | C04 · 0턴 |
| D2 | 미성년자 자녀 대신 착오송금 반환 신청하려면 뭐가 필요해요? | C06 · 0턴 · 친권합의서 |
| D3 | 비법인단체를 대리해서 착오송금 반환 신청하는 서류는? | C05 · 0턴 |
| D4 | 착오송금 반환 신청 온라인으로 하려는데 서류가 뭐죠? | `method=온라인` 잡힘 · 1턴(자격 되묻기) |

## E. 오발동 방지 — 타 업무 질의 ⚠ 반드시 확인

**슬롯이 하나도 안 잡혀야 하고, 되묻기가 뜨면 안 되고, 첨부가 사라지면 안 된다.** 기본 스코프 `msdr` 전제다 —
웹 설정에서 `msdr+dpin`을 고르면 E4는 `보험금신청`으로 잡혀 되묻고, E5는 `제도안내`가 잡히는 것이 정상이다.

| # | 질의 | 기대 |
|---|---|---|
| E1 | 예금보호한도가 얼마인가요? | 슬롯 없음 · 되묻기 없음 |
| E2 | 채무조정 신청하려면 어떻게 해요? | 슬롯 없음 · **채무조정 서식이 나와야 함** |
| E3 | 은닉재산 신고하면 포상금 얼마나 받나요? | 슬롯 없음 |
| E4 | 예금보험금은 어떻게 신청하나요? | 슬롯 없음 · **예금보험금 서식이 나와야 함** |
| E5 | 가지급금이 뭔가요? | 슬롯 없음 |

> **E2·E4가 특히 중요**하다. 08-07에 고친 두 번째 버그가 여기다. 큐폼 슬롯이 잘못 박히면 첨부 필터가 **타 업무 서식을 전부 탈락**시켜 첨부가 0건이 된다.

## F. 함정 — 내용 정확도

슬롯이 아니라 **답변 내용**을 본다.

| # | 질의 | 봐야 할 것 |
|---|---|---|
| F1 | 착오송금 한도가 얼마까지예요? | **1억원**이어야 함. `5천만원`·`1천만원`이 나오면 코퍼스 stale 재발(HOLES H9) |
| F2 | 착오송금 언제까지 신청해야 하나요? | 송금일로부터 **1년 이내** |
| F3 | 보이스피싱 당했는데 착오송금 반환지원 신청되나요? | **대상 아님** + 은행 지급정지 안내 |
| F4 | 토스로 연락처 송금했는데 반환 신청할 수 있나요? | **계좌번호 송금은 대상 / 연락처 송금은 비대상** 구분이 나와야 함 |
| F5 | 새마을금고로 잘못 보냈는데 반환지원 되나요? | **대상 맞음.** (예금자보호제도에서는 비대상이지만 착오송금에서는 대상 — 헷갈리기 쉬움) |

## G. 쿼리 부스트 비교 (토글)

토글 위치 — 정식 웹 UI: 설정 영역의 `쿼리 부스트 · 실험` 체크박스 / 레거시 Streamlit: 좌측 사이드바 토글.

같은 질의를 **토글 OFF → ON**으로 두 번 던져 근거 문서 순위를 비교한다.

| # | 질의 |
|---|---|
| G1 | 대리인이 방문해서 착오송금 반환 신청할 때 서류는? |
| G2 | 미성년자 대신 착오송금 반환 신청 구비서류 |

레거시 Streamlit은 ON일 때 답변 하단에 `부스트 적용 검색어:`를 보여 준다. 정식 웹 UI는 화면에 띄우지 않으므로 API 응답의 `search_q` 필드로 확인한다. **기본은 OFF다** — 검색 동작을 바꾸므로 450셋 회귀 수치가 나오기 전엔 켜지 않는다.

## 참고 — 슬롯이 어떻게 채점되는지 보고 싶으면

```bash
python3 chatbot/qform_extract.py     # 450셋 추출률 + 수기 20문항
python3 chatbot/qform_state.py       # 되묻기 시뮬레이션 + 발동률
```

`qform_extract.py` 맨 아래 `CASES` 리스트에 문장을 추가하고 다시 실행하면 **본인이 던진 질문이 어떤 슬롯으로 채점되는지** 바로 나온다. 오분류를 찾으면 그게 곧 버그 리포트다.

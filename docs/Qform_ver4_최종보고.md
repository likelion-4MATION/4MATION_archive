## §0. 이 스프린트가 한 것 / 하지 않은 것

### 한 것

큐폼(구조화 되묻기 층)을 **착오송금 1업무에서 예금보험금까지** 넓히는 재료를 만들고,
멀티턴 맥락을 **사용자가 보고 고치는 패널**로 꺼냈다.

| 축 | 결과 |
|---|---|
| **B유형 확장** | 예금보험금 조합 테이블 `DPIN-C01~C09` 9행 신설 (착오송금 14행은 **무변경**) |
| **D유형 용어사전** | 지급금 5종 + 채무조정 5종 = 10종. `one_line`·`discriminator` 전건 코퍼스 축자 |
| **멀티턴 패널** | 3구역(`적용 중`/`기억만 함`/`대기 중인 용건`) · X/pass 역할 분리 · TTL=3 · 다중의도 큐 |
| **자연어 입구** | 추출 스코프 파라미터화 + `보험금신청` 규칙 신설. **전환은 보류**(§3 H39) |

### ❌ 하지 않은 것 — **성능 개선을 주장하지 않는다 (K8)**

> "큐폼 확장으로 검색 성능이 올랐다"는 **주장하지 않으므로 재지 않았다.**
> 잰 것은 **"확장이 기존 동작을 망가뜨리지 않았다"** 하나다. **무해 증명이지 개선 주장이 아니다.**

- 쿼리 부스트 **기본 OFF 유지** (G13 미해결 · `rag.py` 동결)
- 되묻기 발동률을 **최적화 목표로 쓰지 않았다** (K12-2)
- D 되묻기 **미구현** (M1 판정 1 — `되묻기 필요` 0건이 근거)
- 동결 8종 **한 줄도 안 고쳤다**

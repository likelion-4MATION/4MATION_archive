## 0. 이 문서의 출발점

착오송금 조합 테이블(v0)을 만들면서 드러난 것 — **"복잡함"이 한 종류가 아니다.**

착오송금은 *구비서류가 조합에 따라 갈리는* 복잡함이었고, 이건 조합 테이블로 풀렸다. 그런데 나머지 5개 업무를 전수로 읽으면 **성격이 전혀 다른 복잡함이 다섯 종류 더** 나온다. 각각 필요한 처리 방식이 다르고, **일부는 조합 테이블로는 원리적으로 안 풀린다.**

유사 하드코딩을 어디에 쓸지 정하려면 이 구분이 먼저다. 그래서 업무별이 아니라 **복잡도 유형별로** 정리한다.

## 1. 요약 — 복잡도 유형 6종

| 유형 | 무엇이 어려운가 | 규모 | 하드코딩 형태 | 규칙 1 충돌 |
|---|---|---|---|---|
| **A. 조건 판정·계산** | 문서에 **결론이 없다**. 사용자 숫자를 넣어 계산·판정해야 나옴 | 5업무 | 결정론 계산함수 | **정면 충돌** |
| **B. 다축 조합 서류** | 결론은 문서에 있으나 **조합으로 골라야** 함 | 4업무 | 조합 테이블 | 없음 (B-1) |
| **C. 상태 의존 분기** | **미래에 갈리는 경로**라 지금 답이 하나로 안 정해짐 | 1업무 | 시나리오 상태기계 | 없음 |
| **D. 근접 용어 혼동** | 용어 4~5종이 서로 비슷. **사용자가 잘못 지목** | 2업무 | 용어 판별 사전 | 없음 |

| **F. 시점·구버전 충돌** | 코퍼스가 **서로 다른 답**을 말함 | 3업무 | deprecated 플래그 | — (탐지) |

## 4. 유형 C — 상태 의존 분기 (조합 테이블로 안 풀림)

**예금보험금 안내 업무 고유의 복잡함.** 저축은행 영업정지 이후 경로가 갈리는데, **갈림길이 미래에 있다.** 사용자도 예보도 지금은 모른다.

```
영업정지
  └─ 45일 이내 자체 경영정상화(유상증자 등)
        ├─ 성공 → 영업재개, 즉시 인출 가능. 약정이율 유지
        └─ 실패 → 계약이전 추진 (통상 3~4개월)
              ├─ 계약이전 성공 → 약정이율 유지, 권리·의무 그대로 승계
              └─ 계약이전 실패 → 파산 → 예금보험금 지급
                    → 이율 = min(약정이율, 공시이율)  ← 여기서만 이율이 깎임
```

근거: `FaqNramtAply#06`, `#09`, `#12`, `#29`, `#30`, `DpsmIbamtExpln#01`.

### 같은 질문에 경로별로 답이 다른 항목

|---|---|---|---|
| 내 예금 이율은? | 약정이율 유지 | 약정이율 유지 | **min(약정, 공시)** |
| 받은 가지급금은? | 인출 시 차감 | 인출 시 차감 | 보험금에서 공제 |
| 미지급이자는? | 영업재개 시 수령 | 영업재개 시 수령 | 지급공고일까지 계산 |

### A를 배제하는 이유 (기획서 §8 B-2 원칙의 연장)

1. **문서에 없는 결론을 만든다.** 규칙 1의 예외를 여는 행위이며, 예외를 한 번 열면 어디까지가 예외인지 경계가 사라진다.
2. **틀렸을 때 피해가 실질적이다.** "1억까지 보호됩니다"를 잘못 계산해 알려주면 사용자가 예금을 옮기지 않는다. 금융 의사결정에 직접 영향을 준다.
3. **입력을 사용자가 모른다.** 보호한도 11축 중 상품 운용내역·상계 대출·지급보증은 사용자가 정확히 답하지 못한다. 잘못된 입력으로 정확한 계산을 해봐야 답은 틀린다.
4. **개별심사가 문서에 명시된 경우가 있다**(A-3 채무조정). 계산해주는 것 자체가 문서에 반하는 답이 된다.
5. **개인정보가 슬롯에 들어온다**(R3). 금액·계좌·상품·대출 잔액은 전부 개인정보다.

> **A에 대한 안전한 답의 형태** — 계산하지 않고 **적용 규칙과 범위를 제시**하고, 필요시 상담으로 넘긴다.
> 예: "동일 금융회사 내 모든 예·적금을 합산해 1억까지 보호되며, 퇴직연금·연금저축·사고보험금은 각각 별도로 1억까지 보호됩니다. 대출이 있으면 상계 후 잔액 기준입니다. 구체 금액은 1588-0037로 문의해 주세요."
> **이건 전부 문서에 있는 문장이다** — 규칙 1 위반이 아니다.

### D(용어 판별)를 최우선으로 두는 이유

- **비용이 가장 싸다.** 용어 정의가 전부 코퍼스 안에 한 문단씩 있다(D-1 5종·D-2 5종). 표로 옮기면 끝.
- **오분류 9건에 직접 대응한다.** 기획서가 이미 측정한 실패다.
- **큐폼 슬롯 하나로 흡수 가능하다.** S2 세부주제 선택지에 5종을 **한 줄 설명과 함께** 나열하면 사용자가 스스로 교정한다 — 착오송금 조합 테이블에서 진행단계를 S2 설명으로 흡수한 것과 **같은 패턴**이다.
- **되묻기 트리거가 명확하다.** 사용자가 "개산지급금"이라 말했는데 문맥이 영업정지 직후면 → "혹시 가지급금을 말씀하시는 걸까요?" 한 턴.

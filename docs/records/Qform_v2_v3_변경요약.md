# Qform ver2 → ver3 변경 요약

> **브랜치** `Qform_ver2` → `Qform_ver3` · **작성** 2026-08-11
> **성격** 팀 공유용 요약. 상세는 `docs/SprintDemoV3_결과공유.md` · 설계 근거는 `docs/QFORM_ARCH_설계스펙.md` rev.5

## 0. 한 줄 요약

**ver2는 E2E를 관통시켰고, ver3는 대화의 막다른 길을 닫았다.**

검색·생성 동작은 **일절 바꾸지 않았다.** 건드린 층은 전이 규칙(`qform_flow`·`qform_state`·`qform_extract`)과 렌더(`app.py`)뿐이며, 따라서 **450셋 회귀 측정 대상이 아니다.** 대신 전이 규칙은 결정론 하니스(HCX 콜 0)로 담보했다.

## 1. ver2에서 끊겼던 것 → ver3에서 닫힌 것

| # | ver2 증상 | 원인 | ver3 처리 |
|---|---|---|---|
| 1 | 답변 턴이 끝나면 슬롯이 리셋 | `start()`가 상태를 통째로 덮어씀 — 턴 간 이월 0 | **슬롯 이월** (T2) |
| 2 | 응답이 슬롯을 못 채우면 같은 질문 반복 | "물었으나 답을 못 얻음"을 기록할 자리 없음 | **`asked` 이력 추가** (T1) |
| 3 | 되묻기를 타이핑으로 답해야 함 | 선택지가 렌더되지 않음 | **선택지 버튼** (T5) |
| 4 | reject가 고정 문구로 끝남 | 다음 행동 없음 | **복구 칩 재노출** (T6) |
| 5 | 첫 화면이 빈 입력창 | 무엇을 물을 수 있는지 모름 | **예시 질의 칩 6개** (T5) |

## 2. 추가된 기능

### 2-1. 슬롯 이월 (T2) — 멀티턴의 실체

**LLM 히스토리 주입이 아니라 상태 재사용으로 구현했다.** 새 콜·새 인프라가 없다.

세 가지 불변 조건:

| 조건 | 내용 | 이유 |
|---|---|---|
| **신규 > 이월** | 새 추출값이 이월값을 항상 덮음 | 슬롯 정정("아니 수취인 기준으로")이 자동 처리됨 |
| **업무 전환 방벽** | `bf`가 직전 턴과 다르면 이월 금지 | 새마을금고·우체국처럼 업무에 따라 답이 정반대인 케이스 차단 |
| **실패는 넓어지는 방향** | 이월 실패 시 슬롯이 비어 첨부가 넓게 남음 | graceful degradation (C3) |

### 2-2. 대화 정책 파라미터 외부화 (T2)

`chatbot/qform_config.py` 신규. **종합 단계 관리자 콘솔이 읽을 자리를 지금 만들어 둔 것.**

| 파라미터 | 기본값 | 허용값 |
|---|---|---|
| `SLOT_CARRYOVER` | `True` | bool |
| `CARRYOVER_TTL` | `2` | 1~5 |
| `CARRYOVER_SCOPE` | `"bf_match"` | `bf_match` \| `global` \| `off` |
| `MAX_ASK_TURNS` | `2` | 1~3 |

- `MAX_ASK_TURNS`는 `qform_flow` 코드 상수에서 이관. 기존 import는 별칭으로 유지
- `CARRYOVER_SCOPE="global"`은 **데모 비교용**이며 기본값 아님

### 2-3. 되묻기 선택지 버튼 (T5)

조합 테이블 생존 행을 버튼으로 렌더. 자유 입력·"잘 모르겠어요"는 유지.

얻은 것 세 개:
- 사용자가 무엇을 답할지 고민하지 않음
- **슬롯 오추출이 구조적으로 0** — 값이 enum에서 직접 옴
- **시연이 결정론이 됨** — HCX 비결정성(`temperature 0.2`, seed 없음)을 타지 않는 경로

### 2-4. 슬롯 칩 수정 (T6)

`qform_flow.edit(state, field, value=None)` 신규. 채워진 슬롯을 클릭해 해제·재선택.

**판정만 하고 실행하지 않는다** — `_step(execute=False)`:

| 판정 결과 | 화면 | 콜 |
|---|---|---|
| 물을 슬롯이 생김 | 되묻기 질문 즉시 렌더 | **0** |
| 물을 게 없음 | `[이 조건으로 다시 답변받기]` 버튼 | **0** (클릭 시 +1) |

근거는 기획서 §7 **"조용히 반영 금지"**. 자동 재생성은 슬롯 3개 고칠 때 생성 3회다.

### 2-5. 후속 질문 추천 (T7)

`chatbot/qform_followup.py` 신규. 조합 테이블 잔여 축에서 결정론 생성.

**클릭은 새 질의가 아니라 슬롯 설정이다.** 재검색하지 않고 `hits`를 유지한 채 후단 필터만 다시 돈다 — T6의 `edit()` 경로 재사용.

> **트레이드오프**: "추천"보다 "필터"에 가깝다. 검색 쿼리 보존의 대가이며, 결과공유 §4에 명기했다.

**착오송금에서만 뜬다.** 조합 테이블이 14행 = 1업무뿐이므로, 다른 업무에서 추천이 비는 것은 정상(graceful degradation)이다.

### 2-6. 정의형 질의 예외 (T3)

`is_definitional()` — "~가 뭔가요/무엇인가요/란" 패턴은 되묻기를 건너뛰고 직행. 슬롯은 유지한다.

패턴을 **좁게** 잡았다. `제도안내` 어휘는 "얼마"·"언제까지"에도 걸리므로, 넓게 잡으면 스코프 게이트가 무력화된다.

> **⚠ 검증 공백**: 450셋 교집합이 0이라 하니스에서 **한 번도 발동하지 않았다.** AC3-1의 "발동 0"은 통과가 아니라 해당 케이스 부재다. 수동 워크스루로만 확인됨.

### 2-7. 예산·에러 처리 (T7)

콜 잔량 경고 배너 · 예산 소진 시 대화 유지 · HCX 실패 문구화(원문 에러·키 미노출).

## 3. 변경사항 (기존 동작이 바뀐 것)

| 항목 | ver2 | ver3 | 영향 |
|---|---|---|---|
| `new_state()` 스키마 | `qform` `ask_turn` `pending_slot` `bf` `base_q` `slots_raw` | **`asked` `turn_no` `slot_turn` 추가** | 상태 스키마 변경. `_clean()`이 `answer()`로 흘리지 않음 |
| `next_question()` | 인자 없음 | **`exclude` 인자 추가** (기본 `None` = 동작 동일) | 하위호환 |
| `_step()` | 판정 후 항상 실행 | **`execute` 인자 추가** (기본 `True` = 동작 동일) | 하위호환 |
| `MAX_ASK_TURNS` | `qform_flow` 코드 상수 | **`qform_config`로 이관** | 별칭 유지 |
| 첨부 후단 필터 | 결과 그대로 | **0건이면 필터 미적용 폴백** + `filter_fallback` 트레이스 플래그 | 안전망. C3 정신 |
| `verify_qform_e2e.py` AC2 | 같은 슬롯 재질문을 기대값으로 박아둠 | **기대값 3줄 개정** | **동결 예외 1건** — 아래 참조 |

### 3-1. 동결 예외 — `verify_qform_e2e.py` AC2 3줄

ver2 기대값이 **반복질문 버그를 스냅샷한 것**이라 T1 이후 충족 불가였다. 그대로 두면 스프린트 내내 exit 1로 남아 T6~T8에서 진짜 회귀가 나도 묻힌다.

- 3줄만 수정. 다른 AC·시나리오 무변경
- 수정 전 sha256을 `DECISIONS.md` D9에 기록
- `AC4-3` → **`AC4-3'`**: "diff = 승인된 AC2 기대값 3줄 외 0줄"
- 해당 줄에 사유 주석 부착

### 3-2. 명세 밖 수정 — `verify_docs.py`

`SPEC: dict = {...}` 같은 타입 주석 대입(`ast.AnnAssign`)을 못 봐서 실재 상수를 "코드에 없다"고 오탐. **검사를 느슨하게 한 것이 아니라 오탐을 고쳤다.**

## 5. 여전히 열려 있는 것

**갭 표 G1~G13 중 닫힌 것은 0건이다.** ver3가 닫은 것은 갭이 아니라 대화의 막다른 길 다섯 개이며, 그건 원래 표에 없던 항목이다.

| 갭 | 상태 |
|---|---|
| G12 관리자 콘솔 | **한 칸 전진** — 파라미터 외부화까지. 콘솔 화면 없음 |
| G13 이중 분류 | ver3에서 실제로 물었음 (후속추천 A안이 부스트 정책 우회) → C안으로 회피 |
| G1 MoAI 라우터 · G4/G9 link route · G5 handoff · G8 용어 사전 · G10 메타부스트 · G11 6업무 확장 | 그대로 열림 |

의도적 미구현(스트리밍 · 부스트 ON · B-2 자격판정 등)은 결과공유 §5에 7항목으로 기재.

## 7. 데모 시 유의

HCX는 seed 없이 `temperature 0.2`라 **생성 문장이 시연마다 흔들린다**(HOLES 기록).

| 결정론 — 시연 근거로 쓸 것 | 비결정론 — 근거로 쓰지 말 것 |
|---|---|
| 되묻기 문구 (ⓐ 템플릿) | 생성 답변 문장 |
| 슬롯 판정 · 생존 행 수 | 답변 내 표현·어순 |
| 첨부 목록·건수 | |
| 선택지 버튼 값 · 후속 추천 항목 | |
| 트레이스 9층 · 콜 회계 | |

체크리스트는 "첨부가 22 → 2건으로 좁혀진다", "2턴 만에 확정된다", "9층 중 6층이 콜 0" 같은 **결정론 지표**로 잡는다.

## 3. 비즈니스 펑션 분류 개선 논의
**기존 문제**
- 질문이 들어오면 키워드 몇 개만 보고 6개 업무 분류 중 하나로 고정하는 하드 분류 방식이었음

**개선 방향**
- 하드 분류 → 소프트 분류로 전환, 해당 분류에 속하면 가중치를 부여하는 방식으로 변경

**추가 고민 및 대안**
- 키워드 확장 여부: 테스트셋 기준으로 키워드를 확장하면 과적합 위험이 있음
- 테스트셋에서만 키워드를 뽑아 넓히면 과적합, 보편적 키워드에 가중치를 주면 오분류 위험이 있음
- 결론: 일단 실험을 진행해보기로 함

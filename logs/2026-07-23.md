## 미팅 후

**논의사항**
- 복잡한 질문을 만들어 데모에 넣고 결과 판별해보기 제안
- 비즈니스 펑션 분류 관련
- 브랜치를 dev 하나로 병합하는 것은 어려울 것으로 판단
- 임의 판단 이슈 — 데모 산출 시 답변 방식이 임의 판단으로 결정된 부분 존재
- Parser 이슈 — 문서 통합 시 어떤 기준으로 병합할지 결정 필요

**논의 결과**
- 목표: 내일까지 발표자료 완성, 스크린샷 및 시연 영상 구상(어떤 화면, 어떤 내용으로 촬영할지) 병행

**비즈니스 펑션 분류**
- 기존 문제: 질문이 들어오면 키워드 몇 개만 보고 6개 업무 분류 중 하나로 고정(하드 분류)
- 개선: 하드 → 소프트로 변경, 해당 분류에 속하면 가중치를 주는 방식으로 전환
- 추가 고민: 키워드 확장 여부 → 테스트셋 기준으로 확장하면 과적합 위험 있음
- 대안: 키워드를 늘려 실험은 해볼 수 있으나, 테스트셋에서만 키워드를 뽑아 넓히면 과적합, 보편적 키워드에 가중치를 주면 오분류 위험 → 일단 실험 진행하기로 함

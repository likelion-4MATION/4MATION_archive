# 예솜24 통합 분기 트리 (구조 분기 + 조건 분기)

- 범례: `[업무]` 업무 분기 · `[자격]` 본인/대리인 · `[주체]` 신청 주어 · `[수단]` 인터넷/방문/우편/이메일 · `[조건]` 적격·판정 조건 · `📎` 첨부서식 · `⚠️` 챗봇 라우팅 실패(RAG 기회)
- 구조 분기 = 신청 절차 경로 / 조건 분기 = 절차와 무관한 적격·판정
- 작성일: 2026-08-03

## 1. 착오송금 반환 신청

```
착오송금 반환 신청
├─[조건] 대상 적격
│   ├─ 대상 금액: 5만원 이상 ~ 1억원 이하 (시행일별: '21.7.6~ 1천만 / '23·'25.1.1~ 1억), 소급 불가
│   ├─ 신청 기한: 착오송금일로부터 1년 이내
│   ├─ 제외: 보이스피싱(전기통신금융사기 특별법 처리)
│   └─ 송금수단: 계좌송금 O / 토스 등 연락처송금 X
│
├─[주체] 착오송금인(송금인)
│   ├─[업무] 반환신청
│   │   └─[수단] 인터넷 · 방문 · 신청서류
│   │        └─[자격] 본인 ↔ 대리인
│   │             └─[주체] 대리인일 때
│   │                  ├─ 미성년자        📎 친권합의서
│   │                  ├─ 군복무자        📎 군복무확인서(발급)
│   │                  ├─ 국외거주/유학생  📎 공관장 공증 위임장(발급)
│   │                  ├─ 법인·단체 대표 / 직원  📎 사업자등록증
│   │                  └─ 비법인단체 대표 / 직원  📎 고유번호증
│   │        📎(공통) 신청서양식 · 금융거래정보제공동의서 · 채권양도통지위임장 · (대리)착오송금반환지원신청위임장
│   └─[업무] 사후관리 (챗봇 칩 미노출)
│        ├─ 신청철회        📎 취소신청서   (온라인)
│        ├─ 매입계약해제     📎 해제신청서   (온라인)
│        ├─ 수령계좌변경     📎 변경신청서   (온라인/방문)
│        └─ 대리인변경       📎 위임해지통지서+위임장 (방문only)
│
└─[주체] 착오송금수취인(수신인)
    ├─ 이의제기        📎 이의제기서      [수단] 인터넷/방문
    └─ 이체수수료 환급  📎 이체수수료환급신청서 [수단] 인터넷/방문
```

## 2. 예금보험금 안내

```
예금보험금 안내
├─[업무] 지급되는 경우
├─[업무] 종류 (각각 별개 노드)
│   ├─ 가지급금 · 개산지급금 · (연관: 파산배당금 · 개산지급금정산금)
├─[조건] 지급 판정
│   ├─ 예금+대출 동시보유 → 대출금 공제(상계) 후 지급
│   └─ 보증채무 보유 → 보증채무 해소 후 신청
└─[업무] 신청
    └─[수단] 인터넷 · 방문 · 보험금신청서류
         └─[주체]
              ├─ 예금자 본인       📎 지급청구 및 동의서
              ├─ 대리인            📎 위임장
              ├─ 미성년자          📎 친권자합의서
              ├─ 군복무자
              ├─ 사망 예금자(상속인)📎 지분신고서·손해담보약정서 (⚠️검증필요)
              ├─ 국외거주/유학생
              └─ 법인 및 단체
```

## 3. 고객 미수령금 신청  ⚠️ FAQ 크롤 0건 (데이터 격차 최대)

```
고객 미수령금 신청
├─[업무] 종류
│   └─ 예금보험금 · 파산배당금 · 개산지급금 정산금
├─[조건] 신청기간(소멸시효, 종류별 상이)
│   ├─ 가지급금·개산지급금 = 지급 종료일까지
│   ├─ 보험금 = 지급개시일부터 5년
│   └─ 배당금·개산지급금정산금 = 통산 10년
└─[수단] 인터넷 · 방문 · 신청서류
     └─[주체]
          ├─ 예금자 본인
          ├─ 대리인
          ├─ 미성년자 → 친권자(친권자 확인 증명서/합의서)
          ├─ 사망 예금자
          ├─ 국외거주/유학생
          ├─ 군인
          └─ 법인 및 단체
```

## 4. 예금자보호제도

```
예금자보호제도
├─[업무] 보호 대상 금융회사
├─[업무] 보호 대상 금융상품
│   └─[권역] 보호 O/X × { 은행 · 보험 · 저축은행(중앙회) · 종금 · 투자매매·중개 }
│        · 상품특성: 외화예금 · 보험 해약환급금 · 원금+이자 합산
└─[업무] 보호 한도 (1인당 1억원)
     └─[조건]
          ├─ 예금자 유형: 개인 / 법인(규모 무관 1억, 단 정부·지자체·한은·금감원·예보·부보금융회사 제외)
          ├─ 상품별 별도한도: 일반예금 1억 | 퇴직연금(DC·IRP·중퇴기금)·연금저축·사고보험금 = 별도 1억
          ├─ 명의 분산: 가족·미성년자 명의별 각각 1억 (실명확인 조건)
          ├─ 회사 합산: 계열 저축은행도 법인 다르면 각각 1억
          └─⚠️ (챗봇 실패) 한 회사 여러계좌 합산 · 예금+대출 상계 · 세전/세후
```

## 태깅 매핑 요약

| 트리 축 | 태깅 필드 | 비고 |
|---|---|---|
| [업무] | `business_function` + `sub_task` | 이미 청크에 존재 |
| [자격] | `qualification` (본인/대리인) | 다중라벨 |
| [주체] | `subject` (다중, '공통'=와일드카드) | 첨부 template 반영됨 |
| [수단] | `method` (인터넷/방문/우편/이메일) | 다중라벨 |
| **[조건]** | **`condition`(신설) 또는 청크 빈 `variant`** | 서식 무관 → Tier A 검색대상 |
| 📎 | `attachment_id` + `retrieval_tier=B` | parent_doc_id 조인 |
